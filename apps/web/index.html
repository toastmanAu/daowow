Round progression

Adversarial attempts

Each button tries a real protocol violation. The engine rejects it with the same error code the on-chain script returns — checks mirror the on-chain scripts, they are not UI-only validation.

Entry shards

Each shard keeps an MMR accumulator of accepted entries; contended shard heads serialize through the UTXO model.

Entries & participants

One entry cell per participant tx. Position ranges are assigned by the shard at entry time.

Settlement

DAOWOW is a non-custodial prize-linked savings protocol on Nervos CKB. This page is a protocol model and testnet driver, not a wallet: balances and cycles are simulated locally (cycles from CKB-VM measurements, see prototype-report.md). The JS core is checked against the same deterministic vectors as the Rust contracts. Wallet integration (CCC) is a later milestone.
